# תוכנית עבודה שנתית – תכנות ורובוטיקה

אפליקציה אינטראקטיבית (קובץ `index.html` אחד) למעקב אחרי ביצוע תכנית הלימודים בתכנות, לפי כיתות. בנויה בדיוק כמו תכנית החינוך הגופני (`pe-app`).

| שכבה | מקצועות |
|---|---|
| כיתה ב' | סקראץ' ג'וניור (טיוטה ראשונית – 30 שיעורים, אפשר לערוך) |
| ג' – ו' | 🤖 רובוטיקה – מיקרוביט (40 שיעורים, ערכת Yahboom WOM) · 🐵 קוד מאנקי (47 שיעורים) |

- בכל שכבה בוחרים מקצוע בלשוניות שמתחת לכפתורים.
- רשימת הכיתות (✏️ ניהול כיתות) משותפת לשני המקצועות של אותה שכבה.
- כל שיעור מסומן בנפרד לכל כיתה: אדום = טרם בוצע, צהוב = בוצע חלקית, ירוק = הושלם בכל הכיתות.
- 📝 ניהול שיעורים: עריכה, הוספה, מחיקה והזזה של שיעורים, וגם הוספה ושינוי שם של יחידות.
- בשדה "פירוט" השורה הראשונה מוצגת תמיד, ושאר השורות נפתחות בלחיצה (למשל פתיחה / הדגמה / תרגול / סיכום במיקרוביט).

## שמירה בענן וניהול קודים

זהה ל-`pe-app`:
- **הזנת קוד** (כל משתמש): חלון הסנכרון ← הזנת הקוד ← "התחבר".
- **הנפקת קוד חדש / עמוד ניהול קודים** (מנהל בלבד, `tamirmaidani@gmail.com`): הכפתור "🔐 ניהול קודים" או הכתובת `index.html#admin`.

האפליקציה משתמשת באותו פרויקט Firebase (`pe-app-db`), אבל שומרת את הנתונים בנתיב נפרד (`artifacts/standalone-coding-app/...`). כך הקודים והנתונים של התכנית הזו נפרדים לגמרי מאלה של החינוך הגופני.
אם `firestore.rules` כבר פורסם עבור `pe-app`, אין צורך בהגדרה נוספת: החוקים חלים על כל `appId`.
אם האתר מתארח בדומיין חדש (לא `t-code-now.github.io`), צריך להוסיף אותו ב-Firebase Console › Authentication › Settings › Authorized domains.

הנתונים המקומיים נשמרים בדפדפן עם הקידומת `coding_app:`, כך שהם לא מתערבבים עם נתונים של אתרים אחרים באותו דומיין.
